## 3. 从当前排期取消

- 公网云服务器、云部署、域名与备案准备。
- 大规模用户容量、多节点高可用、复杂生产监控平台。
- 商业化隐私政策建设、线上用户招募和试点。
- 为上述目标引入 Redis/Celery、云存储、微服务等附加组件。

旧 S5-3 的生产发布与运营门槛不再是作品集交付的前置任务。原计划全文保存为 [PLAN-history](PLAN-history.md)，原路线图保存为 [roadmap-history](roadmap-history.md)；历史停止点只约束当时批次。未来若改变为真实公网服务，需另行评估和授权，不能从本地验收推断生产就绪。

## 4. 仍然有效的安全与许可要求

公开仓库前审查所有拟发布 refs 的历史，不只检查工作树。发现疑似秘密/个人资料只报告与提供方案，绝不自行重写历史或强推。合成 PDF 是允许公开的白名单夹具，真实原件、运行库、凭据、ZIP、日志、备份及未审查截图不公开。Key 不进入 CI，保留已有真实模型显式授权门槛。

负责人已确认原创内容授权来源，正式采用 AGPL-3.0-only 并保留 PyMuPDF；LICENSE、版权范围及页脚告知见 [本轮发布准备](GITHUB-RELEASE-READY.md)。普通历史路径已获准公开，不清洗历史。取消商业化政策工作不免除数据安全和适用许可义务。用户数据本机保存与删除清单的保留限制继续记录，不承诺磁盘或第三方数据立即擦除。
